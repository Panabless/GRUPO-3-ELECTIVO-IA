# GRUPO-3-ELECTIVO-IA

## Qué es la solución
Aplicación de monitoreo del nivel de combustible de una flota de camiones mineros sin operador, con alertas automáticas y una cola de prioridades de reabastecimiento.

## Para quién es
Para el controlador de flota, que hoy coordina más de 30 camiones y no siempre detecta a tiempo los niveles críticos. Beneficia a Operaciones Mina, Planta y Mantenciones.

## Cómo se instala y se ejecuta
Aún no hay código ejecutable. Esta sección se completará cuando exista una primera versión en `src/`.

## En qué estado está
Etapa de diseño: propuesta de valor, caso de uso, maqueta y roadmap (Avance 1) y diseño preliminar de datos (Avance 2).
